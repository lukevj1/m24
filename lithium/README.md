# Lithos: making lithium easy to prescribe

A design proposal and a working research prototype for next-generation lithium monitoring and dosing: something like DoseMeRx for vancomycin, rebuilt around what makes lithium hard.

> **Research prototype. Not a medical device and not for clinical use.** Model parameters are provisional until externally validated on real patients.

## What the prototype shows (simulated; not clinical evidence)

**Titration.** 500 virtual patients, generated by a deliberately different "truth" model and held out during development. Both arms use the same stopping rule.
- *Tests and accuracy:* model-informed dosing needed 4.6 blood tests vs 5.5–5.6 for usual care. The final dose was truly in range for 71% vs 58%.
- *Safety:* 7% vs 21–24% of patients were ever on a dose with a true level above 1.0.
- *Subgroups:* the gains held in older adults and those with eGFR < 60.

**Mistimed levels.** For levels drawn at any time 2–22 h after the dose, the standardisation error halved (0.101 → 0.045 mmol/L). For a correctly timed 12-hour level, the raw value is best, and the design keeps it primary.

**Thiazide started.** A pre-emptive adjustment cut true levels above 1.0 from 54% to 9%. The price was 11% below 0.5, and a check level is still needed.

**Real patients, population level.** The prior agrees with eight published cohorts for most quantities, and is conservative for older adults. Individual-level validation on real data is the next step, and the harness for it is ready.

## The code

| Package | What it does |
|---|---|
| `lithos/` | The engine: exact PK (`pk.py`); priors with provenance (`models.py`); Bayesian individualisation with clearance drift and a timing-aware error model (`bayes.py`); standardised 12-hour level (`forecast.py`); tablet-aware dosing with guardrails and "repeat level first" (`dosing.py`); interaction forecasts (`interactions.py`); guideline-floor scheduling (`schedule.py`); kidney trends (`renal.py`); pregnancy (`pregnancy.py`); toxicity triage (`safety.py`); clinician card and patient messages (`report.py`); worked scenarios (`demo.py`) |
| `sim/` | In-silico trials: virtual population, usual-care and model-informed arms, figures |
| `validation/` | Published-cohort check (`literature.py`); canonical dataset format (`schema.py`); iterative-forecasting evaluator (`evaluate.py`); MIMIC-IV converter (`mimic_iv.py`); synthetic data (`synthetic.py`) |

```bash
cd lithium
pip install numpy scipy matplotlib pytest
python -m lithos.demo                  # five clinical scenarios, simulated patients with hidden truth
python -m pytest -q                    # 39 tests
python -m sim.run_all --n 500          # in-silico trials (~12 min on 4 cores)
python -m validation.literature        # engine prior vs published real-patient cohorts

# individual-level validation, run where the data are allowed to be (see docs/VALIDATION.md)
python -m validation.mimic_iv /path/to/mimic-iv/3.1 /secure/canonical
python -m validation.evaluate /secure/canonical --out report.md
```
