# In-silico trial results

Generated by `python -m sim.run_all` - 500 virtual patients, seed 4242, truth model `truth-perturbed`, engine prior `ensemble`, runtime 12.1 min.

These are simulations: they show whether the mechanisms work under stated assumptions, not clinical effectiveness. See docs/SIMULATION.md for methods and caveats.

Excluded: 1 patient(s) with creatinine clearance below 30 mL/min, for whom the engine declines to plan a start (lithium not recommended; specialist decision).
